# Project Context Overview

This folder contains everything you need to resume work on AVISHKAR EMS without scanning the entire repo:

- **KNOWN_ISSUES.md** – Prioritized list of technical and data-related drawbacks.
- **STATUS.md** – The "honest ledger" tracking progress against the project specification (sections 0-98).
- **WORKLOG.md** – Chronological record of sessions, including what was done, what was not, and concrete next steps.
- **AUDIT_REPORT.md** – Summary of deployment and security audits conducted (Phase 4-5).
- **DEMO_GUIDE.md** – Quick start guide for demo properties.
- **DEPLOYMENT.md** – Deployment instructions, Docker architecture, and CI/CD benchmarks.

### Best Practice
1. **Always read these files first** upon resuming a session.
2. **Update them immediately** after completing a task, identifying a bug, or finishing an audit.
3. Keep the "next steps" in `WORKLOG.md` actionable so the next agent/human can resume in < 60 seconds.
