## 2. Architectural Harmonization
- All new features cleanly integrate into `src/avishkar_ems/` without any changes to vendored code (`src/emhass/`).
- Python standard typing and dataclasses are used throughout for static validation and runtime robustness.
- Full compatibility with the existing Streamlit dashboard (`app/dashboard.py`) and TypeScript API platform (`platform/api`).
